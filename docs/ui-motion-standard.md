# 交件箱前端动效标准

状态：规范生效。动效基准直接采用 [yetone/magpie](https://github.com/yetone/magpie/tree/b1e8eb15a668bbccfcd46977c75602ceaa4d66b3/internal/gui/assets) 的 `app.css` 与 `app.js`（MIT），版本固定为 `b1e8eb15a668bbccfcd46977c75602ceaa4d66b3`。主工作区与服务端页面必须使用这套契约；新建界面、改组件或补动效时先读本文件。基准实现在 `web/motion.css` 和 `web/motion.js`，验收基线在 `scripts/verify-motion.cjs`。

## 1. 目标与范围

动效只解决四件事：让界面显得快、解释元素从哪里来、表达状态变化、保持连续操作的空间关系。它不用于吸引注意力，也不替代数据状态。

| 范围 | 规则 |
|---|---|
| 主工作区、服务端 Web、浏览器授权页 | 使用完整标准 |
| 自定义安装与卸载程序 | 四步只读进度条共用 280ms 移动高亮，使用底部上一步/下一步导航；复用 160ms 按压、140ms 退场 / 240ms 进场；进度条只用 transform 跟随真实进度，支持 reduced motion 和键盘直达；验收运行 `node scripts/verify-setup-ui.cjs` |
| 快捷收集 `quick.html` | 保持轻量；不引入 `motion.js`。只允许短促的颜色状态反馈和焦点外框，禁用进出场动画 |
| 安卓 | 遵守 Material 3 动效规范；不复制桌面 Web 参数 |
| 图表 | 首次渲染不动画；数据刷新只做必要状态提示，不使用装饰性循环 |

`web/motion.js` 是行为层，`web/motion.css` 是布局与降级层。两者一起作为最小运行时；不引入 GSAP、Framer Motion 或其他动画库。新组件优先复用既有类名和 API，只有出现可复用的新模式时才扩展运行时。

## 2. 基础令牌

缓动：

```css
--motion-ease: cubic-bezier(.2, .8, .2, 1);    /* 状态、进出场 */
--motion-out: cubic-bezier(.23, 1, .32, 1);    /* 按压和快速退出 */
--ease-drawer: cubic-bezier(.32, .72, 0, 1);   /* 抽屉 */
```

时长：

| 类型 | 时长 | 说明 |
|---|---:|---|
| 悬停、选中、焦点态 | 160ms | 只过渡颜色、边框、不透明度 |
| 按压 | 160ms | `scale(.96)`；图标按钮 `scale(.9)` |
| 行或小面板进出场 | 180–240ms | 只用于增量数据或异步结果 |
| 抽屉 | 210ms | 与空间位置变化配合 |
| 菜单 | 开 240ms，关 150ms | 始终锚定触发按钮 |
| 分段控件 | 280ms | 主题切换、手机二级页和同组 tab 共用同一块移动背景 |
| 弹窗开 | 440ms | 使用弹簧曲线；键盘或 reduced motion 时直接显示 |
| 弹窗关 | 220ms；遮罩 180ms | 必须有安全完成期限 |
| 导航弹簧 | 420ms 周期，0.84 阻尼 | 只作用于一个共享高亮块 |
| 二级导航展开 / 收起 | 300ms / 240ms | `cubic-bezier(.32,.72,0,1)`，高度与上下边距折叠 |
| 二级条目进入 | 260ms | 上移 6px 起步；40ms 初始延迟，每项再加 20ms |
| 二级选中条 | 240ms | `cubic-bezier(.23,1,.32,1)`；按下即可移动 |
| 主页面切换 | 140ms 退场 + 240ms 进场 | 旧页轻退、新页进入；标题和工具区域位置保持稳定 |
| 二级内容切换 | 220ms | 从 `opacity:.5`、`translateY(2px)` 进入 |
| 侧栏模式切换 | 280ms | 左上角开关控制图标 / 图标加文字；宽度和主内容同步过渡 |
| 主题切换 | 250ms | 只交叉过渡颜色、边框和阴影；首次渲染直接显示 |

只允许动画 `transform`、`opacity`、`clip-path` 和 SVG `stroke-dashoffset`。悬停/选中使用 160ms 过渡 `color`、`background-color`、`border-color`。禁止动画 `width`、`height`、`top`、`left`、`margin`、`padding`。例外直接沿用 Magpie：共享高亮块允许尺寸变化；二级导航折叠允许动画 `height`、`margin-top` 和 `margin-bottom`，条目必须 `flex:none` 保持自身尺寸；左上角侧栏模式开关允许动画 `width` 和 `grid-template-columns`。后两个例外仅限侧栏，不能用于业务列表或快捷收集。

禁止使用毛玻璃、视差、光晕、粒子、大面积颜色渐变和超过一个循环动画。`backdrop-filter` 一律关闭。

## 3. 组件契约

### 首次渲染与列表

内容必须在第一次渲染就完整可见；不能为了等待动画结束而隐藏内容。不要用 `setTimeout` 延迟业务状态。列表数据到达前可以显示明确的加载状态，但骨架屏和状态文本必须可访问。

只有增量插入才使用 `entering` 或一次性 240ms 进出场。首屏不使用 stagger；如确需展示分批结果，只处理前 8 项，每项间隔 40ms。`row.flash` 只表示新消息或状态变化，时长不超过 2 秒。

### 按钮和列表行

按钮复用全局按压规则。导航、菜单项、命令面板项不缩放，只改背景。禁用按钮不播放动画。所有可交互元素保留 `:focus-visible`；行级可点元素使用 `cursor:default`，选中态和键盘焦点承担可点暗示。

页面根节点和主布局容器不显示铺满窗口的焦点外框；按钮和表单控件仍保留键盘焦点。命令面板的搜索框固定在结果列表上方，用面板边框表达焦点，避免输入框外轮廓被裁成横线。页面禁止横向溢出；文件表格等需要横向滚动的区域使用自身滚动容器。

### 导航和分段控件

导航使用一个 `nav-highlight`，分段控件使用一个 `segment-highlight`。真实按钮保留语义状态：激活项由 `active` 和 `aria-current` 表示，高亮块只是 `aria-hidden` 装饰。

以下情况必须直接对齐，不做弹簧追赶：

- 键盘导航；
- `prefers-reduced-motion: reduce`；
- 首次挂载；
- 窗口 resize；
- 页面从隐藏恢复；
- 动画运行时再次快速点击。

目标矩形必须始终收敛到当前激活按钮，误差小于 0.5px。布局变化或动画失败也不能留下错位高亮。

### 二级导航、页面和信息密度

设置、统计和消息来源的子页放到当前主项下面，缩进 16px、内边距 8px、1px 竖线；只使用一条中性的子项选中背景。子项使用 `tablist/tab`、`aria-selected` 和 roving tabindex，方向键可以切换。

二级目录展开/收起按上表执行。收起时立刻 `inert` 并移出键盘路径；快速连点清掉旧的退出目录，旧动画不得删除新目录。改变信息密度、字体或窗口尺寸时，共享高亮立即对齐目标。键盘和减少动态效果模式不播放入场动画。

主页面切换先轻退再进入，内部二级内容使用 2px 位移；重复点击当前项不重播。表单节点保持原位，切换子页不得丢弃草稿。切换主页面从顶部开始，同页刷新保留滚动位置。手机宽度把二级导航放到页面顶部的分段栏，桌面二级项和手机分段栏使用同一个滑块。

二级内容切换和渲染触发的同步都保留滚动位置；只有主页面切换回到顶部。任何监听 DOM 变化的同步路径禁止移动视口。

密度统一使用 `workspace.css` 的令牌：舒适导航至少 40px，紧凑至少 32px；表单和面板同步调整留白，文字大小独立使用 rem。手机主要操作和输入框至少 44px。快捷收集维持独立固定尺寸，不导入主界面导航和动效。

### 弹窗

主工作区不用裸 `showModal()` / `close()` 控制交互，改用：

```js
uiMotion.openDialog(dialog);
await uiMotion.closeDialog(dialog, returnValue);
```

规则：

- 立即调用原生 top-layer 语义；焦点和 inert 行为不能等动画结束。
- 指针触发时，弹窗从触发元素折叠展开；键盘触发时直接显示。
- 关闭向来源收合；来源不可用时向下 10px 并缩放到 `.97`。
- 遮罩同步淡入淡出，但无模糊。
- 正在关闭的弹窗被再次打开时，必须取消旧动画、保留表单草稿并保持 `open`。
- 关闭动画必须有 450ms 安全期限；动画事件失败也能关闭。
- `Escape` 走取消路径，不绕过状态清理。

### 菜单

菜单锚定触发按钮，固定宽度不超过 `100vw - 16px`，四周至少留 8px。打开时按方向平移 6px、缩放 `.94`，关闭时用 `menu-ghost` 克隆退出；ghost 不接收焦点、事件或文件拖放。

打开后焦点进入第一个菜单项；`ArrowDown`、`ArrowUp`、`Home`、`End` 循环移动；`Tab` 关闭；`Escape` 关闭并归还焦点到触发按钮。滚动或 resize 立即关闭。`aria-expanded` 与真实状态同步。

### 抽屉、拖拽和快捷收集

文件抽屉进出用 `--ease-drawer`，只移动抽屉本体。拖拽时显示全窗目标态和明确的可放置区域；呼吸提示只存在于拖拽期间。拖到指定任务/区域走指定路径，不触发 AI；拖入空白区域才触发归类。

快捷收集窗口固定尺寸、无进出场、不加载 `motion.js`。它可以改背景、边框和焦点外框，但收下文件后不得自动关闭。

### 状态与图表

异步分析入队后立即显示“分析中”，结果、失败和重试用稳定徽章表达，不用动画补偿延迟。循环加载点只允许表示真实 pending 状态；任务完成后立即移除。成功提示最多一个焦点或轻微描边动画。

ECharts 的 `animation` 保持 `false`。数据刷新通过重绘和文本状态解释；不添加装饰性图表动画。

安装器检测到已有安装后，先显示当前版本、目标版本、安装位置和数据保留说明；仅点击“确认更新”后才能写入程序文件。打开窗口、前后切换步骤或动效结束均不得启动更新。只有显式命令行 `--silent` 才能跳过界面确认。安装完成页提供默认勾选的“打开交件箱”；点击“完成”时才按勾选状态启动程序。取消勾选只关闭安装器；卸载完成页不提供启动选项。

## 4. 可访问性与性能

所有动画必须在 `prefers-reduced-motion: reduce` 下关闭。键盘路径必须跳过方向性进出场，直接显示目标并移动焦点。动画不能遮挡焦点外框，也不能创建新的 tab stop。

同一交互最多一组运行中动画；不得连续叠加 overlay。持续动画只允许用于真实加载或拖拽提示。动画每帧只写 compositor 属性；共享高亮块必须在页面隐藏、控件不可见或用户切换输入方式时停止。

动画只是表达层。API 响应、乐观更新、状态机和表单校验不允许依赖动画结束事件。

## 5. 必测行为

改动 UI 或动效时运行 `scripts/verify-motion.cjs` 或包含它的 `scripts/verify-native.cjs`，至少覆盖：

1. 首次渲染的 `.stagger-item` 立即具有 `opacity:1` 且 `transform:none`。
2. 连续切换导航后，弹簧高亮最终与激活按钮重合。
3. 按下普通按钮有按压反馈；释放后打开弹窗。
4. 关闭动画中再次打开同一弹窗，弹窗仍打开且表单草稿保留。
5. 菜单连续开关后没有残留 `.menu-ghost`，`aria-expanded` 正确。
6. 键盘打开菜单时焦点进入菜单，`Escape` 后焦点归还触发按钮。
7. reduced motion 下没有 `running` 动画。
8. 390px 视口内菜单完整落在视口内。
9. 全流程没有页面错误。
10. 舒适 / 紧凑 / 大字切换后导航、输入框和面板实际变化，高亮保持对齐；360–1280px 下侧栏宽度与主内容预留一致。
11. 二级目录快速切换后没有残留退出节点；表单草稿、方向键、命令面板焦点回退正常。
12. 桌面用 `scripts/verify-native.cjs`，浏览器用 `scripts/verify-browser-experience.cjs`；两者复用 `verify-motion.cjs` 与 `verify-experience.cjs`。

不满足其中任何一条，不能合并。

## 6. 新增或修改的判断顺序

1. 这个动效解释状态或空间关系吗？只是“好看”就不做。
2. 能复用按钮、导航、分段、弹窗、菜单、抽屉既有模式吗？能则复用。
3. 会阻塞输入、焦点、网络状态或业务提交吗？会则改。
4. reduced motion、键盘、390px、中断重试下都可用吗？否则改。
5. 能被 `verify-motion.cjs` 验证吗？不能则先补验收，再写动效。

例外必须同时更新本文件和验收脚本。快捷收集保持轻量是硬边界；任何新能力不得把完整动效运行时加回 `quick.html`。

## 7. 服务与额度控件（Magpie 控件扩展）

这些控件复用现有配色、密度令牌、字体和动效运行时，不添加独立风格。

| 控件 | 布局与行为 | 动效 |
|---|---|---|
| `.chart-mode` 分段控件 | `tablist/tab`、左右/Home/End 键切换、单个选中背景；同项重复点击不重播 | 共用 `uiMotion.syncSegments()`，高亮 280ms；键盘与 reduced motion 直接定位 |
| `.service-toolbar` | 页面标题下方靠左，默认/自定义切换整套服务视图；保存服务选择后生效 | 内容复用 220ms 二级进入；首次读取不播动画 |
| `.managed-overview` | 可用积分与签到并排；签到关闭时积分占满；窄屏纵排 | 首屏完整可见；刷新金额就地更新 |
| `.credit-panel` | 中性边框、数字使用正文色和等宽数字；兑换率与服务状态降为辅助信息 | 不播放计数动画 |
| `.checkin-panel` | 奖励与签到按钮清晰分层，已签到显示完成状态；请求中禁用 | 共用按钮反馈；数据变化不重建设置表单 |
| 用量概览 | 始终四列指标（窄屏两列）；余额独立于用量指标；来源跟随模型连接，不设独立的默认/自定义 tab；同时过滤图表、模型汇总、最近记录 | 单位切换复用分段高亮；ECharts 保持 animation:false |
| 模型连接表单 | 接口字段按默认/自定义隐藏；分析偏好共享；切换不丢弃草稿或已保存密钥 | 只过渡内容 opacity/transform，禁止对业务面板高度做动画 |

### 共享元素与连续布局

同一元素跨状态存在时优先保留 DOM，并使用 `data-motion-key` 标记身份，调用 `uiMotion.relayout(container, change)`。运行时记录切换前后的位置，以 FLIP 位移在 280ms 内衔接；只动画 transform/opacity，不动画业务面板宽高。新的操作从当前显示位置接续，首次渲染、键盘与 reduced motion 不播放。不要同时标记父子节点，避免叠加位移。仅在状态切换时调用，轮询更新不播放装饰动画。

侧栏以选中背景表示当前位置，按键不额外添加外圈焦点高亮；表单和其他交互控件保留焦点反馈。

### 服务能力与统计联动

默认服务的接口地址、密钥、模型和图片能力由站点管理员统一配置。普通用户在默认页只看能力状态；自定义模式的图片开关仅影响自己的接口。后端解析默认服务时强制使用站点图片能力，不能受个人开关覆盖。

统计来源只有一个事实来源：模型连接中保存的服务选择。统计页不再提供默认/自定义切换；默认页展示积分和签到，自定义页展示 Token 用量。每种来源的响应、模型和调用记录都必须对应同一来源。

Magpie 视觉补充（沿用本仓库固定基准）：优先系统字体和平台原生窗口行为；中性灰双层面板；强调色只用于主要操作和状态；桌面保持紧凑清晰，手机扩大点击区域；行级按压仅加深背景；菜单和分段控件复用统一运行时。用户提供的新版本研究可作为参考，毛玻璃和阴影等差异不自动覆盖本规范已确认的约束。


### 面包屑

面包屑使用语义导航容器，每一层标签与分隔符各有独立节点。桌面相邻节点间距统一 12px，手机 8px；禁止用空格拼接斜杠，禁止对所有 span 添加 margin。当前页只标记一个 aria-current。长标题单行截断，窄屏优先隐藏工作空间根节点及其分隔符，保留主栏目与二级页，不挤压顶栏操作。
