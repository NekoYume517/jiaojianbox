# 交件箱前端动效标准

状态：规范生效。主工作区与服务端页面必须使用这套契约；新建界面、改组件或补动效时先读本文件。基准实现在 `web/motion.css` 和 `web/motion.js`，验收基线在 `scripts/verify-motion.cjs`。

## 1. 目标与范围

动效只解决四件事：让界面显得快、解释元素从哪里来、表达状态变化、保持连续操作的空间关系。它不用于吸引注意力，也不替代数据状态。

| 范围 | 规则 |
|---|---|
| 主工作区、服务端 Web、浏览器授权页 | 使用完整标准 |
| 快捷收集 `quick.html` | 保持轻量；不引入 `motion.js`。只允许短促的颜色状态反馈和焦点外框，禁用进出场动画 |
| 安卓 | 遵守 Material 3 动效规范；不复制桌面 Web 参数 |
| 图表 | 首次渲染不动画；数据刷新只做必要状态提示，不使用装饰性循环 |

`web/motion.js` 是行为层，`web/motion.css` 是布局与降级层。两者一起作为最小运行时；不引入 GSAP、Framer Motion 或其他动画库。新组件优先复用既有类名和 API，只有出现可复用的新模式时才扩展运行时。

## 2. 基础令牌

缓动：

```css
--motion-ease: cubic-bezier(.2, .8, .2, 1);    /* 状态、进出场 */
--motion-out: cubic-bezier(.23, 1, .32, 1);    /* 按压和快速退出 */
--ease-drawer: cubic-bezier(.32, .72, 0, 1);   /* 抽屉 */
```

时长：

| 类型 | 时长 | 说明 |
|---|---:|---|
| 悬停、选中、焦点态 | 100–150ms | 只过渡颜色、边框、不透明度 |
| 按压 | 140ms | `scale(.97)`；图标按钮 `scale(.93)` |
| 行或小面板进出场 | 180–240ms | 只用于增量数据或异步结果 |
| 抽屉 | 210ms | 与空间位置变化配合 |
| 菜单 | 开 240ms，关 150ms | 始终锚定触发按钮 |
| 分段控件 | 280ms | 同组内移动同一块背景 |
| 弹窗开 | 440ms | 使用弹簧曲线；键盘或 reduced motion 时直接显示 |
| 弹窗关 | 220ms；遮罩 180ms | 必须有安全完成期限 |
| 导航弹簧 | 420ms 周期，0.84 阻尼 | 只作用于一个共享高亮块 |

只允许动画 `transform`、`opacity`、`clip-path` 和 SVG `stroke-dashoffset`。悬停/选中可以用 100–150ms 过渡 `color`、`background-color`、`border-color`。禁止动画 `width`、`height`、`top`、`left`、`margin`、`padding`。共享高亮块是唯一例外：由 `motion.js` 的 rAF/WAAPI 控制，并且只操作一个装饰元素。

禁止使用毛玻璃、视差、光晕、粒子、大面积颜色渐变和超过一个循环动画。`backdrop-filter` 一律关闭。

## 3. 组件契约

### 首次渲染与列表

内容必须在第一次渲染就完整可见；不能为了等待动画结束而隐藏内容。不要用 `setTimeout` 延迟业务状态。列表数据到达前可以显示明确的加载状态，但骨架屏和状态文本必须可访问。

只有增量插入才使用 `entering` 或一次性 240ms 进出场。首屏不使用 stagger；如确需展示分批结果，只处理前 8 项，每项间隔 40ms。`row.flash` 只表示新消息或状态变化，时长不超过 2 秒。

### 按钮和列表行

按钮复用全局按压规则。导航、菜单项、命令面板项不缩放，只改背景。禁用按钮不播放动画。所有可交互元素保留 `:focus-visible`；行级可点元素使用 `cursor:default`，选中态和键盘焦点承担可点暗示。

### 导航和分段控件

导航使用一个 `nav-highlight`，分段控件使用一个 `segment-highlight`。真实按钮保留语义状态：激活项由 `active` 和 `aria-current` 表示，高亮块只是 `aria-hidden` 装饰。

以下情况必须直接对齐，不做弹簧追赶：

- 键盘导航；
- `prefers-reduced-motion: reduce`；
- 首次挂载；
- 窗口 resize；
- 页面从隐藏恢复；
- 动画运行时再次快速点击。

目标矩形必须始终收敛到当前激活按钮，误差小于 0.5px。布局变化或动画失败也不能留下错位高亮。

### 弹窗

主工作区不用裸 `showModal()` / `close()` 控制交互，改用：

```js
uiMotion.openDialog(dialog);
await uiMotion.closeDialog(dialog, returnValue);
```

规则：

- 立即调用原生 top-layer 语义；焦点和 inert 行为不能等动画结束。
- 指针触发时，弹窗从触发元素折叠展开；键盘触发时直接显示。
- 关闭向来源收合；来源不可用时向下 10px 并缩放到 `.97`。
- 遮罩同步淡入淡出，但无模糊。
- 正在关闭的弹窗被再次打开时，必须取消旧动画、保留表单草稿并保持 `open`。
- 关闭动画必须有 450ms 安全期限；动画事件失败也能关闭。
- `Escape` 走取消路径，不绕过状态清理。

### 菜单

菜单锚定触发按钮，固定宽度不超过 `100vw - 16px`，四周至少留 8px。打开时按方向平移 6px、缩放 `.94`，关闭时用 `menu-ghost` 克隆退出；ghost 不接收焦点、事件或文件拖放。

打开后焦点进入第一个菜单项；`ArrowDown`、`ArrowUp`、`Home`、`End` 循环移动；`Tab` 关闭；`Escape` 关闭并归还焦点到触发按钮。滚动或 resize 立即关闭。`aria-expanded` 与真实状态同步。

### 抽屉、拖拽和快捷收集

文件抽屉进出用 `--ease-drawer`，只移动抽屉本体。拖拽时显示全窗目标态和明确的可放置区域；呼吸提示只存在于拖拽期间。拖到指定任务/区域走指定路径，不触发 AI；拖入空白区域才触发归类。

快捷收集窗口固定尺寸、无进出场、不加载 `motion.js`。它可以改背景、边框和焦点外框，但收下文件后不得自动关闭。

### 状态与图表

异步分析入队后立即显示“分析中”，结果、失败和重试用稳定徽章表达，不用动画补偿延迟。循环加载点只允许表示真实 pending 状态；任务完成后立即移除。成功提示最多一个焦点或轻微描边动画。

ECharts 的 `animation` 保持 `false`。数据刷新通过重绘和文本状态解释；不添加装饰性图表动画。

## 4. 可访问性与性能

所有动画必须在 `prefers-reduced-motion: reduce` 下关闭。键盘路径必须跳过方向性进出场，直接显示目标并移动焦点。动画不能遮挡焦点外框，也不能创建新的 tab stop。

同一交互最多一组运行中动画；不得连续叠加 overlay。持续动画只允许用于真实加载或拖拽提示。动画每帧只写 compositor 属性；共享高亮块必须在页面隐藏、控件不可见或用户切换输入方式时停止。

动画只是表达层。API 响应、乐观更新、状态机和表单校验不允许依赖动画结束事件。

## 5. 必测行为

改动 UI 或动效时运行 `scripts/verify-motion.cjs` 或包含它的 `scripts/verify-native.cjs`，至少覆盖：

1. 首次渲染的 `.stagger-item` 立即具有 `opacity:1` 且 `transform:none`。
2. 连续切换导航后，弹簧高亮最终与激活按钮重合。
3. 按下普通按钮有按压反馈；释放后打开弹窗。
4. 关闭动画中再次打开同一弹窗，弹窗仍打开且表单草稿保留。
5. 菜单连续开关后没有残留 `.menu-ghost`，`aria-expanded` 正确。
6. 键盘打开菜单时焦点进入菜单，`Escape` 后焦点归还触发按钮。
7. reduced motion 下没有 `running` 动画。
8. 390px 视口内菜单完整落在视口内。
9. 全流程没有页面错误。

不满足其中任何一条，不能合并。

## 6. 新增或修改的判断顺序

1. 这个动效解释状态或空间关系吗？只是“好看”就不做。
2. 能复用按钮、导航、分段、弹窗、菜单、抽屉既有模式吗？能则复用。
3. 会阻塞输入、焦点、网络状态或业务提交吗？会则改。
4. reduced motion、键盘、390px、中断重试下都可用吗？否则改。
5. 能被 `verify-motion.cjs` 验证吗？不能则先补验收，再写动效。

例外必须同时更新本文件和验收脚本。快捷收集保持轻量是硬边界；任何新能力不得把完整动效运行时加回 `quick.html`。
