# 0.6.16

- 桌面提醒从“启动与更新”中独立出来，成为“设置 → 桌面提醒”，并统一复选框垂直对齐和测试通知间距。
- 所有操作结果 Toast 固定显示在右下角；出现待办状态建议卡时，Toast 会平滑叠到卡片上方，卡片关闭后回到底部。
- 手动修改待办状态后，不再立即弹出要求改回原状态的反向建议；主动重新核对或材料发生变化后才恢复建议。
- 命令面板改用与普通弹窗完全相同的入场弹簧、退场位移和遮罩淡入淡出，并保留快速关闭再打开时的中断恢复。
- 修正移动端命令面板的安全区间，搜索结果在固定搜索框下方独立滚动，不再遮住顶部操作栏或底部导航。
- 补充右下角 Toast、状态建议抑制和弹窗动效一致性的浏览器自动验收。
- 更新安装时先通知旧版本正常关闭并释放数据库、凭证和采集器锁；安装器与卸载器不再强杀进程，也不会误结束正在运行的自身。
- 修复窗口隐藏到后台后再次启动客户端时，已有实例不能可靠回到前台的问题。
- 数据库升级前会先合并 WAL 并校验完整性，再生成非空备份；异常的 0 字节或中断备份会自动重建，不再阻断启动。
- 主数据库损坏或缺失时，会自动尝试原位修复并回退到最新完整备份，同时恢复附件和加密密钥；没有恢复条件时只隔离损坏文件并保留原路径，供后续人工找回。

桌面安装包继续内置 SnowLuma、微信数据库读取组件、Node 与 Python 运行依赖，覆盖安装保留本地数据。Android 使用固定签名，可直接覆盖升级。
