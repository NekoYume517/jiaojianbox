# 0.6.8

- 修复另一台 Windows 设备出现采集配置读取失败（InvalidConfig）、退出（1）的问题：桌面发送 UTF-8 配置时，采集程序现直接按 UTF-8 解码输入字节，不依赖系统区域设置或默认输入编码。
- 同时固定打包入口的 stdin 编码；使用自定义 Python 时也通过相同的字节读取协议。
- 配置异常日志增加原因分类、输入长度、编码和 JSON 错误位置；不记录原始配置或凭据。
- 安装包真实启动验收加入中文群名、联系人、Emoji 与微信路径，防止纯英文配置掩盖编码问题。
- 更新下载新增真实进度条、已下载/总大小、速度与剩余时间；未知大小也持续显示已接收字节，切换页面保留进度。
- 设置、筛选、日期范围等选项统一为 Magpie 分段标签，使用同一套选中样式、平滑高亮和键盘规则。
- 浏览器授权页支持注册；邮箱验证完成后自动建立网页会话，并返回原桌面授权确认页。
- 修复旧分析记录缺少字符数时显示“输入 undefined 字”的问题，补全新记录的输入字符统计。
- 保留 0.6.7 的代理环境修复、脱敏进程日志和退出原因。

SnowLuma 2.1.1、Node 运行环境、PyInstaller 微信采集程序及 Python 依赖均内置，无需从 SnowLuma 原仓库下载。覆盖升级保留数据，Android 沿用固定签名。

采集日志默认路径：`%APPDATA%/交件箱/collector/collector-process.jsonl`；也可在消息来源 → 高级与调试 → 检查读取状态中查看。
