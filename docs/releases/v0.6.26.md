# 0.6.26

## 自动分析

- 自动深度分析统一采用按会话的通知窗口批处理：同一聊天一分钟内到达的消息合并成一次模型调用，图片消息可随窗口一起分析。
- 移除本分支此前并行开发的阶段分析调度，分析和待办归属以主线的批处理结果为准。

## 微信与 QQ 采集

- 自动探测微信版本；微信 4.2 及以上直接使用兼容读取层（wechatauto-replica 1.2.9），不再每轮尝试会失败的 WCDB 直读。
- 会话读取结果附带微信版本号，便于排查不同客户端版本的兼容性。
- 自己发送的消息保留方向标记，兼容读取层会去掉账号目录名的 `_9353` 类后缀再比对 sender。
- 修复本地构建版无法启动采集组件的问题，并补齐桌面运行时的微信、QQ 组件目录。
- 通知详情与主界面顶栏显示 QQ / 微信采集连接状态（绿=已连接、橙=连接中、红=失败、灰=未启动）。

## 随主线合入

- 消息图片的本机读取、上传与视觉分析，以及消息方向、发送者展示。
- 更新安装流程、安装器存活检查和旧版覆盖升级的稳定性修复。

Windows 安装包与 Android APK 均由 0.6.26 同一版本构建。服务端升级保留 `/data` 数据卷，桌面端和安卓端覆盖升级保留本地数据。
