# 0.6.24

## 重点更新

- 通知详情与主界面顶栏显示 QQ / 微信采集连接状态（绿=已连接、橙=连接中、红=失败、灰=未启动）。
- 深度分析改为按会话阶段执行：群聊静默约 2 分钟后，把这段时间的消息打包成一次 AI 调用，直接给出本阶段产生的任务；同一件事跨多条消息只生成一个待办。
- 修复本地构建版无法启动采集组件的问题，并补齐桌面运行时的微信、QQ 组件目录。

## 微信与 QQ 采集

- 自动探测微信版本；微信 4.2 及以上直接使用兼容读取层（wechatauto-replica 1.2.9），不再每轮尝试会失败的 WCDB 直读。
- 会话读取结果附带微信版本号，便于排查不同客户端版本的兼容性。
- QQ 采集继续通过本机 SnowLuma/SnowCat OneBot 接口读取获准消息。

## 界面与文档

- 「分析如何进行」说明更新为阶段分析流程。
- 更新微信采集文档的版本兼容说明与已知限制。

Windows 安装包与 Android APK 均由同一版本构建。服务端升级保留 `/data` 数据卷，桌面端和安卓端覆盖升级保留本地数据。
