# 0.6.24

## 更新流程

- 点击“运行安装程序”后，交件箱保持运行，不再主动退出或结束安装器。
- 更新安装器独立于桌面采集进程运行；需要覆盖文件时由安装器请求旧版交件箱正常清理并退出。
- 安装器等待旧版释放数据库、采集器和锁文件后，再替换程序文件。
- 对旧版交件箱增加兼容退出请求：仍会走正常清理流程，不使用强制结束进程。

## 稳定性

- 采集 helper 继续由桌面程序的 Windows Job 管理；只有安装器可以脱离主程序生命周期。
- 增加安装器存活、交件箱退出请求、旧版覆盖升级、数据保留、新版启动和安装界面回归检查。

Windows 安装包与 Android APK 均由 0.6.24 同一版本构建。桌面端覆盖升级保留本机数据。
