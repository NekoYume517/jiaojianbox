# 0.6.21

## 重点更新

- Android 发布包改为正式 Release 构建，继续使用固定证书签名，可覆盖安装旧版本并保留本机数据。
- 安卓登录令牌改用 Android Keystore 的 AES-GCM 加密保存，并禁止系统备份导出令牌。
- 在线连接强制 HTTPS，补充对 SSRF、内网地址、重定向和 DNS 重绑定风险的防护。
- 收紧 CORS 与内容安全策略，统一检查浏览器和插件发出的外部请求。
- 发布流水线新增固定签名证书校验、Release APK 不可调试检查、构建证明和完整校验文件。

## 稳定性与性能

- SQLite 启用 WAL，完善连接池、数据库完整性和升级前校验，降低并发读写阻塞。
- 服务端为静态资源启用 gzip 和缓存，Markdown、代码高亮、公式与图表资源改为按需加载。
- 后台任务增加 panic 隔离与恢复；修复流式响应完成事件与取消操作的竞态。
- 清理已退役的 Electron 兼容运行文件，发布链路统一为 Go 服务端与 Wails 桌面端。

## 界面与文档

- 修正搜索框、文件图标、计数单位、Toast 位置和多个页面的滚动与间距问题。
- 更新 Android 签名、部署、网页外壳和微信采集文档，补充默认云端数据处理与本地采集边界。

Windows 安装包与 Android APK 均由同一版本构建。服务端升级保留 `/data` 数据卷，桌面端和安卓端覆盖升级保留本地数据。
