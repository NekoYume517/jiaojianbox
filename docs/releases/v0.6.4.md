# 交件箱 v0.6.4

本次更新统一桌面端与网页工作台的导航和动效，修复信息密度、页面边缘横线及命令面板体验问题。

## 界面与交互

- 舒适 / 紧凑模式真正作用于左侧导航、列表、输入框和面板留白；文字大小单独生效。
- 设置、消息来源和统计加入 Magpie 风格二级导航：缩进层级线、移动高亮、展开与收起。
- 动效规范直接参考 Magpie 源码：主页面淡入 240ms、内部切换 220ms、子目录展开 300ms / 收起 240ms，支持快速连续切换与减少动态效果。
- 切换二级页保留未保存的表单草稿；切换主页面从顶部开始，同页刷新保留滚动位置。
- 修复侧栏与主内容宽度不一致、字体设置不完全生效，以及窄窗口下导航和表单挤压。
- 移除右侧旧收纳竖条，将收纳入口和待整理数量移到顶栏。
- 修复页面底部异常描边、横向溢出、命令面板粗横线、背景滚动与键盘焦点回退。
- 主题切换加入颜色过渡，原生 Windows 标题栏使用目标配色。快捷收集保持轻量。

## 下载与升级

- Windows：下载 `JiaojianBox-Setup-0.6.4-x64.exe`，这是自定义安装程序，包含 QQ SnowLuma、PyInstaller 微信采集工具及必要运行依赖。无需另行安装 Python。
- Android 修正 CI 固定签名路径，并在发布前比较 APK 与固定密钥的证书，避免以后更换签名。
- Android：下载 `JiaojianBox-v0.6.4-android-debug.apk`。本次同步版本号，手机界面继续使用原生 Material 3。
- Windows 使用原安装位置覆盖升级即可。账号配置和离线工作区保留；安装程序不会删除未列入安装清单的用户文件。
- 服务端与桌面共用前端代码，自建服务端需单独更新部署才能获得新版界面。

## Android 旧版兼容说明

已核对 GitHub v0.6.2 APK，其临时签名与本次恢复的固定签名不同，无法直接覆盖安装。请先将本机数据同步到云端或完成备份，再卸载旧版安装本版；未同步的离线数据不能在卸载后自动保留。本次恢复使用原本保存在 CI 中的固定签名，以后的官方版本继续使用此密钥。Windows 覆盖升级不受此问题影响。
