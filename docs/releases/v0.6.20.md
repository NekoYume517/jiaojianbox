# 0.6.20

## 重点更新

- 合并 PR #2 的群聊摘要与三层分诊：本地规则、批量预分诊、深度分析依次处理，减少无关消息造成的模型调用和 Token 消耗。
- 修正分诊的跨用户公平调度，单个账号积压不会阻塞其他账号；闲聊结果会同步结束对应 Agent 任务，避免触发历史出现幽灵会话。
- 新增 SnowCat QQ 连接器预览，支持应用内选择实例和会话、内置 Node 依赖、正常退出 QQ 后替换文件、备份与恢复 `winmm.dll`、SnowCat 配置和兼容 DLL。
- 新增 SnowCat“检查并修复”：会请求 QQ 正常退出、恢复部署记录中的原生文件、清理异常残留并校验运行时。
- 插件导入继续兼容旧版 `desktop-1` 清单和顶层清单格式，已有自由配置、插件数据与执行历史可在升级后继续使用。
- 通知与任务附件查询继续使用批量读取，降低数据库往返和列表加载成本。

## 合规与文档

- 新增 MIT License 和贡献者名单。
- README 顶部增加合规与隐私声明。
- 新增默认服务端 `jiaojianbox.bansonic.top` 的数据处理范围、删除和备份说明。
- 新增微信本地只读采集协议，明确选择会话、缓存、密钥、媒体和云端上传边界。
- README 已按当前 Wails v3 + WebView2 桌面架构更新，明确安装包和服务端不包含 Electron/FastAPI 运行链路。

## 升级说明

- 覆盖升级保留现有数据库、附件、账号、分享、收集记录、触发历史和本机工作区。
- 服务端升级保留 `/data` 数据卷，并继续执行数据库完整性检查和不可变升级备份。
