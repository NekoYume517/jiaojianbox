# 0.6.25

## 微信与 QQ 消息

- 区分自己、他人和系统消息；自己发送的内容保留在历史中，但不自动创建待办。QQ 过滤回声消息。
- 过滤纯文字表情、动画表情与系统噪声，保留带实际文字的消息和图片。
- 微信可按需读取本机已下载图片，支持受账号权限保护的图片展示和模型视觉分析；未下载或读取失败时不伪造图片结果。
- 同一账号、同一会话的新消息进入 60 秒滚动窗口，新消息顺延窗口截止时间，到时整批分析；图片、链接和补充说明追加到原待办，不重复建任务。
- 分析中的窗口摘要实时显示，切页后继续处理，停止按钮会取消当前模型请求，后续消息进入下一窗口。

## 界面与稳定性

- 修复移动端命令面板在滚动后高度为零的问题，保留与普通弹窗一致的开闭动效。
- 修复触发历史输入区溢出、消息独立滚动、空白状态间距及上下文用量弹层开关。
- 中文输入法组合期间不重建搜索框，保持输入焦点和已输入内容。

Windows 安装包与 Android APK 均由 0.6.25 同一版本构建。桌面端覆盖升级保留本机数据；图片仅在本机已保存且成功读取时上传至当前工作区，是否发送给模型由“模型支持图片分析”设置控制。
