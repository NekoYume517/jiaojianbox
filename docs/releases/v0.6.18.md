# 0.6.18

- 修复插件二级页被导航同步反复卸载、重新挂载的问题；切换插件 tab 和子 tab 时保持页面状态稳定。
- 插件“设置与调试”保存改为原位更新，不再重建整个插件管理页，展开状态、输入内容和焦点不会丢失。
- 改进第三方插件兼容性；`agent-connect` 修复版只扫描本机 CLI 路径并缓存结果，不再通过探测命令启动完整 Agent 进程。
- 全局搜索的类型切换、搜索框和筛选字段统一左右边界，桌面端与窄屏布局均按同一内容网格对齐。
- 修复回收站、待办模板和搜索空状态中的 SVG 图标被浏览器按默认尺寸黑色拉伸的问题。
- 增加插件生命周期、设置稳定性和生产力页面响应式布局回归测试。

Windows：下载 `JiaojianBox-Setup-0.6.18-x64.exe`。Android：下载 `JiaojianBox-v0.6.18-android-debug.apk`。
