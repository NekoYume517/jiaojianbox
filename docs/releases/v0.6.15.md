# 0.6.15

- 桌面端新增 Windows 10/11 原生待办提醒，支持测试通知、通知中心展示和点击回到对应待办。
- 提醒设置与现有外观、快捷收集和站点管理保持同一套界面与动效规范。
- Android 在线界面改为 M3 登录门与共享网页工作区组合，保留通知、待办、文件、分享、统计和我的等完整入口。
- Android 新增文件导入导出连接器与系统日历连接器，网页操作可直接调用原生能力。
- 统一桌面、服务端和 Android 的任务与二级 tab 动效、共享高亮、弹窗开闭和减少动态效果行为。
- 修复移动端命令面板在短屏幕和 320/360/390/412px 宽度下超出屏幕、遮住顶栏或底部导航的问题。
- 修复部分二级页面切换后滚动位置跳动、tab 高亮重建和弹窗动画中断的问题。
- 新增完整 UI、控件、响应式、文件拖放、进度反馈与动效验收规范，并加入冻结参考页面。
- 增加启动日志与升级备份诊断，便于定位数据库或采集组件启动失败。

桌面安装包继续内置 SnowLuma、微信数据库读取组件、Node 与 Python 运行依赖，覆盖安装保留本地数据。Android 使用固定签名，可直接覆盖升级。
