# v0.6.11

## 收集工作台

- 新增收集工作台，支持拖动编排文字、数字、邮箱、日期、单选和文件字段。
- 支持通过 AI 对话生成、调整表单草稿，采用真实的多轮工具调用（读取任务、增删字段、排序、设置规则），并流式反馈到画布上，AI 改到哪里，界面就同步长到哪里。
- 支持必填、精确长度、格式、数值范围、文件扩展名、唯一字段及重复禁止或覆盖规则。
- 支持 CSV / XLSX 名单导入、姓名与学号联动，以及服务端名单整行匹配。
- 支持本浏览器提交历史、恢复填写、修改已有提交和同一浏览器限填一次。
- 新增收集列表表格、Excel 导出和附件 ZIP 导出，可用字段模板命名附件。
- 沿用统一控件与动效，优化工作台操作栏、窄屏布局和不保存草稿的表单预览。

## 统一控件与统计

- 名单导入、材料与附件上传统一为同一套自定义文件选择控件，不再出现浏览器原生“选择文件”样式，目录拖拽也能直接落入。
- 统计范围选择改为可换行的分段选项卡，窄屏下不再被裁切。
- 最近调用新增“表单设计”类型，AI 表单设计会如实计入使用统计。

## 采集稳定性

- 修复退出后可能残留的 QQ / 微信采集进程：采集桥接在标准输入关闭、IPC 断开、输出错误或父进程消失时自动退出，不再对用户自己的 QQ 客户端误发终止信号。

需同步更新服务端。升级采用增量建表，保留现有数据库、文件与提交记录。浏览器限填一次基于本地浏览器凭证，严格限制提交者时应配合名单与唯一学号规则。JavaScript 只运行于浏览器，关键规则应同时配置声明式规则由服务端复核。

验证：Go 测试与 vet、Python 57 项测试、浏览器流程与动效验收、采集进程生命周期检查、安装与覆盖升级数据保留检查通过。AI 生成交互以模拟上游完成端到端测试，真实模型服务按用户配置调用。
