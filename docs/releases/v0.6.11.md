# v0.6.11

- 新增收集工作台，支持拖动编排文字、数字、邮箱、日期、单选和文件字段。
- 支持通过 AI 对话生成、调整表单草稿，以及浏览器端 JavaScript 扩展校验。
- 支持必填、精确长度、格式、数值范围、文件扩展名、唯一字段及重复禁止或覆盖规则。
- 支持 CSV / XLSX 名单导入、姓名与学号联动，以及服务端名单整行匹配。
- 支持本浏览器提交历史、恢复填写、修改已有提交和同一浏览器限填一次。
- 新增收集列表表格、Excel 导出和附件 ZIP 导出，可用字段模板命名附件。
- 沿用统一控件与动效，优化工作台操作栏、窄屏布局和不保存草稿的表单预览。

需同步更新服务端。升级采用增量建表，保留现有数据库、文件与提交记录。浏览器限填一次基于本地浏览器凭证，严格限制提交者时应配合名单与唯一学号规则。JavaScript 只运行于浏览器，关键规则应同时配置声明式规则由服务端复核。

验证：Go 测试与 vet、Python 57 项测试、浏览器流程与动效验收、安装与覆盖升级数据保留检查通过。AI 生成交互使用模拟响应测试，真实模型服务按用户配置调用。
