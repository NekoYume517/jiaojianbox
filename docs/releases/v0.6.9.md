# 0.6.9

- QQ 和微信采集现在按来源隔离：QQ 连接失败、未登录或找不到实例时，已选择的微信会话继续读取；反过来微信打开失败也不影响 QQ。
- 只连接一个来源时，不会再要求另一个来源同时存在聊天。
- 修复部分微信长文本消息显示为「[文本]」的问题：采集组件内置 zstd 解码依赖，打包自检也会验证该依赖。
- 文本消息中的 XML 形态内容按原文保留，不再误判成媒体占位符。
- 通知列表的行内「忽略」「建待办」不再被整行点击和时间文本拦截。
- 更新安装包支持系统代理与 4 线程分段下载，界面显示进度、速度和剩余时间。
- 安装或卸载前只结束目标安装目录内的旧进程，避免升级时文件占用。
- 插件页面支持拖入 JSON / ZIP 插件包导入，并补充开发者文档入口。
- 文件上传显示进度、速度和剩余时间。
- 部署包内置插件开发引导，便于自动化工具优先按插件契约扩展程序。

覆盖安装保留本地队列、授权和数据；Android 继续使用固定签名。
