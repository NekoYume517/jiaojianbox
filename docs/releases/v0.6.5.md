# 0.6.5

- 新增完整信任的插件契约 v1，支持导入 JSON/ZIP、启停、配置、删除、一级与二级 tab 注册，以及界面/宿主 API 扩展。
- 任务事件与插件任务事务入队，支持页面内处理器与独立 Worker、租约、心跳和幂等结果回传。插件包、配置、数据、执行记录持久保存。
- 提供插件开发指南、任务自动化可导入样例、通用外部 AI 工具 Worker 样例。
- Windows 启动时提前检查单实例，重复启动唤起现有窗口；托盘隐藏与最小化状态可恢复。
- Windows 采集与本机工具子进程由 Job Object 管理，主进程异常结束时系统回收其后代。
- 修复卸载启动器对子窗口隐藏状态的继承，使用明确维护界面配置目录；从正常 Uninstall.exe 入口验收整个卸载链路。
- 更新先展示确认页面；完成页默认勾选打开交件箱；安装与卸载共用只读步骤条与动效。

升级仍只替换安装清单拥有的程序文件，工作区数据保留。服务端继续使用原数据目录和持久卷，不清空 /data。插件自己的数据迁移应遵循开发指南，完整信任插件本身必须由用户审阅来源。
