# 0.6.23

## 输入与搜索

- 修复通知和待办搜索框无法输入中文的问题。输入法组合拼音期间不再重建输入框或刷新列表，上屏后再执行筛选。
- 统一文本输入框、文本域和下拉框的焦点边框，移除错位的外框与重复光晕。

## 待办排序

- 支持按创建时间升序或降序、截止时间升序或降序、名称 A–Z 或 Z–A 排序。
- 自动保存用户的排序选择，刷新或重新打开后继续使用。
- 没有截止时间的待办始终排在截止时间排序的末尾。

## 验证

- 新增中文输入法组合事件、六种排序、排序持久化、焦点框和窄屏布局回归检查。
- Windows 安装包与 Android APK 均由 0.6.23 同一版本构建，覆盖升级保留本机数据。
