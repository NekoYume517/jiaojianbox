# 0.6.7

- 修复采集进程继承 SOCKS 代理或无效证书环境变量时可能出现 ImportError、退出（1）的问题。采集内部 HTTP 客户端使用明确的直连配置。
- 记录采集启动、退出、异常类型和 stderr 尾部，保留具体失败原因，避免只显示退出码。
- 消息来源 → 高级与调试 → 检查读取状态可查看最近日志和日志路径。日志脱敏凭据、限制大小并轮转，不主动记录聊天消息或完整配置。
- 安装包验收新增真实采集启动测试，验证在代理、证书环境异常时仍能完成初始化，覆盖 PyInstaller 自检未经过的运行路径。

日志位于用户数据目录下 `collector/collector-process.jsonl`，默认路径为 `%APPDATA%/交件箱/collector/collector-process.jsonl`。保留上一份日志 `collector-process.jsonl.previous`。

Windows 安装程序内置 SnowLuma、PyInstaller 微信采集程序与 Python 依赖、拖拽工具及 VC++ 运行库。无 WebView2 的设备由安装器联网获取微软运行时。覆盖升级保留用户数据，Android 沿用固定签名。
