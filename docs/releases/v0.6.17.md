# 0.6.17

- 微信采集优先通过 WCDB 原地查询加密数据库，不再在数据库每次变化时整库解密和复制。首次缺少密钥时仍会回退兼容读取；密钥缓存成功后续自动使用 WCDB。
- WCDB 增量消息支持跨 500 条分页，短时间内积压大量消息也不会跳过较早内容；微信轮询调整为 3 秒并继续支持分批昵称查询。
- Windows 文件拖动监听改为 Explorer 作用域内的 WinEvent 事件驱动，移除了 32ms 全局轮询和拖拽热路径上的整页快照请求。快捷收集窗提前创建，自动呼出不抢焦点。
- 桌面插件契约升级到宿主 API 1.1：启用、页面挂载、请求/响应、命令、配置、渲染、快照、服务和触发器均有独立超时与错误隔离；坏插件不会阻断宿主或健康插件。
- 插件支持包内相对模块、触发事件串行排队和最新快照补跑；连续失败的请求钩子会进入冷却期，插件管理器可查看异常、耗时和执行记录。
- 新增待办提醒、回收站、文件预览、全局搜索、任务模板、重复通知追加、收集进度和 Android 本地通知调度等日常功能。
- 安装包继续内置 SnowLuma、WCDB、PyInstaller 微信采集组件和必要运行依赖；覆盖升级保留本机数据，Android 使用固定签名与递增 versionCode。

Windows：下载 `JiaojianBox-Setup-0.6.17-x64.exe`。Android：下载 `JiaojianBox-v0.6.17-android-debug.apk`。
