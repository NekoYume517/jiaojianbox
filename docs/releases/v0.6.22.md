# 0.6.22

## 摘要与通知

- 摘要页增加“清除全部摘要”；清除后只解除摘要绑定并恢复原始通知，不删除消息内容。
- 已由批量分诊判为闲聊或无关的消息不再在摘要视图重复平铺。

## QQ 连接器

- QQ 版本不兼容时只在连接器提示区保留“获取最新 QQ”操作，移除实例行里重复的按钮。
- 保持 SnowCat 生命周期修复、运行时恢复和诊断状态与 0.6.21 一致。

## 发布

- Windows 安装包与 Android APK 均由 0.6.22 同一版本构建。
- 桌面端和 Android 覆盖升级继续保留本机数据，服务端升级继续保留原 `/data` 数据卷。
