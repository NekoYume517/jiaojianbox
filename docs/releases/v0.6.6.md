# 0.6.6

- 统一 Magpie 风格控件、共享元素位移和分段高亮，优化二级导航、信息密度与面包屑间距。
- 修复设置等二级页面点击后滚动跳顶；去掉侧栏按键时出现的外圈焦点框。
- 模型连接支持默认服务器 AI 与自定义接口切换，保留接口草稿与密钥。
- 默认模型的图片能力由管理员统一配置，个人设置仅控制自定义接口。
- 统计跟随正在使用的服务，默认展示积分和签到，自定义展示 Token 用量；分别统计响应和调用记录。
- 管理员可配置每人存储配额（默认 10 GB）、免配置 AI、积分兑换率与每日签到奖励。

Windows 提供自定义 EXE 安装程序，内置 SnowLuma、PyInstaller 微信采集程序及其依赖、拖拽辅助工具和 VC++ 运行库。未安装 WebView2 的设备会在安装时联网获取微软运行时。

升级保留工作区和用户数据。服务端更新继续使用原数据目录及持久卷；首次部署保留超级管理员初始化流程。

Android 使用原有固定签名，支持覆盖安装。
