# 0.6.19

- 通知、QQ、微信和手动事件统一进入触发会话；同一来源持续复用上下文，并支持续聊、停止和跨会话调用。
- Agent 可并行调用待办、进度、通知和文件工具，完整展示工具参数、结果与耗时；支持 Markdown、代码高亮、数学公式和 Mermaid 图表。
- 上下文接近窗口上限时自动压缩较早消息，保留近期原文；模型连接支持自定义上下文窗口。
- 页面导航不再终止正在执行的 Agent。离开触发历史后任务继续运行，返回时会恢复实时状态、最终结果和按会话保存的草稿。
- 提高连续工具调用上限；达到边界时返回可继续执行的正常结果，不再误报“本轮未完成”。
- 修复修改待办时丢失任务 ID、误删后重建以及未确认删除的问题；现有附件、历史和关联信息原地保留。
- 插件可直接使用标准 `fetch()` 和全部受保护应用 API；继续支持页面、二级页面、命令、服务、触发器和请求/响应钩子。
- 修复通知、待办、回收站、模板、分享与触发器页面的间距、滚动、弹窗、Tab 动画和窄屏布局。
- 安装包继续内置 SnowLuma、WCDB、PyInstaller 微信采集组件及必要运行依赖；覆盖升级保留本机数据。

Windows：下载 `JiaojianBox-Setup-0.6.19-x64.exe`。Android：下载 `JiaojianBox-v0.6.19-android-debug.apk`。
