# 2026-11-08 更新与验收

桌面 0.3.1：设置 → 桌面快捷收集，可关闭全部呼出方式，分别显示拖拽框、随手记、文件列表；标题栏拖动后记忆位置，显示器变化时限制在可见区域。文件放入后清除自动收起状态，焦点变化、主窗口显示和鼠标释放均不会自动关闭。Esc、关闭按钮可主动收起。

Android 0.2.0：原生 Compose Material 3，跟随系统深浅色，底部导航、顶部刷新、新建待办 FAB、系统文件选择器、任务和通知详情底部面板、搜索与状态筛选、账户退出。修复 multipart 上传、成功授权未保存、任务修改提前污染本地对象、JSON null、取消请求响应资源释放、大文件读取阻塞主线程和无限制占用内存、会话切换状态隔离、日历时间偏移重复重写及失败误报。

验证：25 项 pytest；3 项快捷窗逻辑测试；实际打包 Electron 离屏自动化覆盖内容开关、禁用呼出及原有上传/任务/统计等交互。Android assembleDebug 与 lintDebug 成功。没有连接 Android 设备，未进行真机触控、分享及系统日历端到端验收；未操作用户桌面运行中的旧版应用。
