# 微信本地只读采集协议

生效日期：2026-11-13

本协议说明交件箱 Windows 桌面端如何读取微信消息。它不是微信、腾讯或第三方读取组件的官方授权文件；使用者仍需遵守适用法律、平台规则、组织制度和个人信息保护要求。

## 1. 前置条件

- 交件箱只在 Windows 桌面端提供微信采集。
- 用户必须已经安装、登录并保持自己的微信客户端可用。
- 用户必须在交件箱内阅读并确认采集合规提示，然后主动选择账号和要监听的会话。
- 使用者只能处理自己有权访问的消息和文件，不得使用交件箱获取他人设备、账号或数据库。

## 2. 本地读取过程

1. 交件箱自动检测本机微信数据目录，也允许用户手动指定目录。
2. 读取器在本机定位 `session.db` 和账号数据；优先使用随安装包提供的 WCDB 兼容读取组件查询数据库。
3. 兼容读取模式可能创建仅属于当前账号的本地解密 SQLite 快照，以便读取受限数据库。
4. 密钥缓存只保存上游读取器生成的、由 Windows DPAPI 加密的 `keys.json` 字节。交件箱不在界面、日志、上传队列或服务端保存该密钥缓存。
5. 读取器只轮询用户选中的会话，并把文本、会话标识、发送者标识、时间和有限的卡片/引用元数据规范化为通知。图片、语音、视频和普通文件通常转换为类型占位，不会自动上传媒体文件字节。
6. 采集进程检测到微信账号变化、数据库不可读或读取器失败时会停止该轮读取并显示诊断，不尝试猜测登录密码、暴力破解或接管账号。

首次缺少可复用数据库密钥时，兼容读取器会打开本机已登录的微信进程并读取其内存，以定位数据库密钥；提取完成后优先通过随包 WCDB 对已获授权的数据做只读查询。交件箱不改写或注入微信登录密码，不保存完整进程内存，不调用微信发送接口，也不替代用户操作微信客户端。该行为可能被安全软件识别为敏感进程访问并产生提示，使用者应在知情且获授权的设备上启用。

## 3. 本机缓存

- 微信临时解密目录位于交件箱本机采集状态目录下，并尽量按账号和进程隔离。
- 正在使用的解密目录需要独占读取锁，避免多个采集进程互相覆盖。
- 过期 `live-account-*` 临时目录按当前实现最多保留 7 天；列表读取目录最多保留 1 天；遗留临时文件按 1 小时阈值清理。
- 诊断文件只记录错误类型、阶段、系统错误码和涉及的文件路径，不主动写入聊天正文或数据库密钥。
- 退出交件箱后，采集子进程应结束；无法清理的加密缓存会由下一次启动按周期清理。

## 4. 数据上传边界

- 选择本机离线工作区时，规范化消息只进入本机数据库和本地补传队列。
- 登录云端时，选中会话的新消息和必要元数据上传到当前指定的交件箱服务端。默认服务端为 `https://jiaojianbox.bansonic.top`。
- 自动采集不读取并上传微信数据库原文件、数据库根密钥、媒体缓存目录、聊天导出目录或整个 `xwechat_files` 目录。
- 用户主动拖入或选择文件时，该文件按普通交件箱附件上传；这不属于微信自动采集。
- 通知分析会按用户选择的上下文发送到配置的模型服务。发送范围受上下文条数、触发器规则和用户选择影响。

## 5. 使用者义务

使用者应：

- 只收集执行工作所必需的消息，并关闭无关会话。
- 向他人在群聊中可能被处理的信息提供必要告知或取得合法依据。
- 设置设备锁屏、账号密码、磁盘加密和交件箱/服务端访问权限。
- 不把含他人聊天原文、附件、邀请码或分享链接的内容发到无关群聊或公开渠道。
- 在目的完成或授权撤回后停止采集，并删除本机队列、服务端数据、分享和备份中的相关内容。
- 不将本项目用于骚扰、跟踪、未授权监控、账号接管或其他违法用途。

## 6. 已知限制

- 微信或 WCDB 更新可能导致读取器暂时不可用，交件箱不以破解账号密码的方式恢复访问。
- 自动采集不保证覆盖撤回消息、历史消息、加密媒体、租户/企业限制或微信尚未落库的内容。
- 第三方读取组件、WCDB 和微信客户端分别受其自身许可与使用条款约束。
- 删除当前记录不会追溯删除已经下载、导出或被他人复制的文件。

## 7. 停止与清理

用户可以在消息来源页停用微信采集并移除会话选择。还可以在交件箱设置中删除本机数据；云端数据需在对应服务器账号内删除，并联系自建服务器运营者清理其独立备份。

更完整的云端数据处理范围见 [隐私与数据处理](../PRIVACY.md)，第三方来源与许可证见 [第三方与来源](../THIRD_PARTY_NOTICES.md)。
