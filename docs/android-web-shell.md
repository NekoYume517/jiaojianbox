# Android 网页套壳预览版

版本：0.6.21。在线模式采用 M3 登录门、共享网页工作区、Android 文件与日历连接器。APK 保持原应用 ID 和永久签名，可以覆盖原有签名一致的版本；不删除旧本机数据。

## 界面与登录

- 登录和手机连接器使用原生 Compose Material 3，提供系统深浅色。
- 默认服务端地址隐藏；可在登录页切换到自建服务器，浏览器授权直接访问该服务器。
- 授权完成后自动进入 WebView；同时保留账号密码登录。
- 工作区直接使用仓库 `web/`。Gradle 构建时把同一套前端打进 APK，页面与动效不用再维护一份原生实现。API 和同步仍连接登录选择的服务器。
- 手机连接器在工作区右上角“更多”菜单中；手机隐藏仅桌面适用的消息采集导航。插件仍只支持桌面。
- 预览阶段，已有的离线工作区继续使用原来的原生界面与存储，尚未改成网页离线内核。它与在线 WebView 模式明确分开；不要声称此版已把离线内核全部迁移。

## 文件连接器

网页文件入口调用 Android 系统文件选择器，可多选；导出数据包、收集 Excel、附件 ZIP 和下载文件通过系统“保存到”选择位置。取消保存会回到网页，不能显示保存成功。

从其他应用分享到交件箱的文件会等待用户确认导入，登录前收到的文件保留到登录后。连接器中的导入上传到当前账号的文件收纳区；指定字段上传仍走网页字段原有流程。原生传输使用流式读取与写入，显示实际字节与速度，不把大附件整体编码成 Base64。

## 日历连接器

用户显式授权读取和写入日历后选择可写日历，手动同步全部待办，或在具体待办中点“添加到系统日历”。可开启“在工作区更新时同步”，仅在应用运行时检查，至少间隔 30 秒。

事件锚点是待办截止时间，提前提醒按待办提醒时间转换为相对分钟；无提醒时使用截止时提醒。已提交、归档、删除或移除截止时间的任务会清理本连接器在所选日历创建的相应事件。

事件归属包含服务器、用户和待办标识，不按任意名称或模糊任务文字删除其他日历事件。这是单向同步，用户在系统日历中修改不会反向修改服务器。切换日历不会自动迁移旧日历事件；关闭同步不会擅自删除日历里已有的事件。

## 桥接边界

`web/mobile.js` 在普通网页与桌面端不生效，只有 Android 注入标记时启动。网页会话从原生持久化会话初始化；令牌不进入 URL。连接器使用受限方法集，通过 `WebMessagePort` 校验消息来源、当前顶层页面和会话令牌；普通脚本弹窗由原生 M3 对话框承接。外部站点在浏览器中打开，文件下载仅接受当前服务的 `/api/` 路径。没有开放任意本机文件路径读取、任意代码执行或通用反射接口。

## 构建和验证

```powershell
cd android
.\gradlew.bat --offline :app:assembleDebug
cd ..
python scripts/verify-android-signing.py --apk android/app/build/outputs/apk/debug/app-debug.apk
node scripts/verify-mobile-shell.cjs
```

日常调试包使用本地 Android 调试签名，只用于开发。接受验收或对外分发时必须构建 `assembleRelease`，并通过 `scripts/verify-android-signing.py --require-release` 检查固定签名和不可调试标记。

浏览器验证脚本要求本机隔离测试服务（默认 `127.0.0.1:8776`，可设 `JJB_MOBILE_TEST_SERVER`），会创建临时测试用户；原生桥传输是 mock，API 是真实本机服务。它验证会话衔接、文件上传、下载/日历命令和移动导航，不替代真实设备上的系统选择器或 CalendarProvider 检查。

本轮已在 Android 模拟器完成原生登录到网页工作区加载，发现并修复了 Android 平台 `JSONObject` 与桌面 JVM 版本方法不一致造成的闪退。模拟器在后续系统文件选择检查期间退出；系统文件实际保存、分享导入和日历写入/权限流程需要继续在手机验收，不能只以 APK 编译成功判为已通过。
