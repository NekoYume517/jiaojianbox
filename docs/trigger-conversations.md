# 触发器与持续会话

触发历史一级按微信触发器、QQ 触发器、插件触发器、手动触发分组，二级是群聊、私聊或手动创建的会话。

聊天身份使用用户、来源、采集账号、聊天 ID；发送者不参与分组。同名群不会合并，不同账号也不会共享历史。手动会话仍可以创建多个，旧的单会话对话归入手动触发。

新消息分析读取这段持续会话的摘要与未压缩消息，不再按最近 N 条或手动勾选的消息拼接上下文。达到模型窗口 80% 时压缩前 50% 的活跃消息，最新输入保留原文。模型窗口在模型连接中配置，默认服务使用管理员配置。

自动通知通过持久化 analysis_jobs 排队，同一会话的自动分析和手动续聊共用执行槽。等待者取消不会停止正在运行的那一轮。进程重启恢复队列仍沿用原有机制。

自动分析新消息控制通知是否入队。已移除自动新建与追加待办开关，自动处理和手动续聊都由所在会话的权限控制：默认完全访问，可创建与补充待办；手动切换受限模式后只读。跟进通知由模型识别是否对应原任务，不能把所有同群任务直接合并。

旧的逐条通知会话按原始消息的聊天身份事务迁移；保留消息 ID、手动续聊和旧摘要，迁移可重复执行。消息找不到原始聊天 ID 时，使用原会话记录作为回退，不猜测其他群的身份。

## 会话显示

回复使用圆角矩形气泡，正文通过本地 Markdown 渲染器显示 CommonMark/GFM（表格、任务列表、删除线、代码高亮）、脚注、KaTeX 数学公式和 Mermaid 图表。流式正文逐帧合并更新，图表在回复完整后渲染。HTML 先清理事件属性及主动内容，代码按原文复制。

工具调用按真实执行阶段显示：开始时发送 running，结束时使用同一工具调用 ID 更新 done/error，保留参数、结果预览及耗时。自动通知分析与手动 Agent 续聊共用显示格式，不生成虚假的思考记录。

## 实时执行与停止

通知入队时立即创建会话和执行记录。每轮执行保存排队/运行状态、逐步收到的模型输出及工具状态。触发历史在独立轻量轮询中更新这些字段，不重建气泡或输入框。通知分类的 JSON 输出逐步提取摘要，手动 Agent 输出按 Markdown 显示。

停止按钮调用服务端的会话 stop 接口，按执行 ID 校验用户与会话归属，取消真实上游请求，保留已收到内容与工具记录。取消的自动任务标记 cancelled，不能进入自动重试；同会话后续排队任务继续运行。重启后重新排队未结束的自动任务；手动未完成轮次标记 interrupted。停止不回滚已经完成的操作。
