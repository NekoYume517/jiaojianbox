# 分享与收集

分享与收集需要连接服务器，离线模式隐藏入口。分享链接由当前服务器生成，访问者无需安装客户端。

## 分享待办

在待办详情选择「分享待办」，或从「分享」页面新建分享。默认公开、仅可查看、无密码、无限期。生成链接后自动复制。

访问范围支持仅自己、已登录、指定用户名、公开。访问权限支持仅可查看、可下载文件、可修改；后一级包含前一级。可修改包含待办标题、说明、截止时间、进度和文件增删。

密码需要 6 至 128 位，编辑时留空保留已有密码，也可以显式移除密码。更改密码后旧的解锁授权立即失效。过期或删除的链接无法继续访问。

## 作为收集者

在待办详情开启「收集表单」，系统自动生成链接。通过「表单设置」配置可见说明、截止时间、材料清单、命名要求、已有文件，以及允许提交的材料、回执和备注。可以在保存之前预览当前设置。姓名与联系方式为选填。

分享页面按收集表单展示提交记录，收集者可以下载提交文件。关闭收集表单立即停止访问，但保留提交记录与已经收到的文件。再次开启会生成新的收集链接。明确删除分享会删除该链接的提交记录，已收集文件仍保留在待办中。

上传受单文件、单待办及账号空间配额限制，失败的上传不会留下提交记录或占用空间。上传时显示真实进度与速度。查看者无法访问收集者未开放的字段或文件。

## 数据与更新

分享设置、加密的链接标识、提交记录和文件关联保存在原服务端数据库中，文件仍在原文件目录。升级只新增表与索引；服务端沿用现有版本备份流程，不删除原有数据。部署新版服务端后才会启用分享 API。

## 表单工作台

在分享卡片或收集任务详情打开「收集工作台」。表单设计提供文字、多行文字、数字、邮箱、日期、单选、文件字段；支持拖入、重排和上下移动。字段可设置必填、精确长度、正则格式、数字范围、文件扩展名和唯一值。

没有配置 AI 时可以直接编辑；已有模型服务时，可用自然语言生成或调整草稿。AI 生成结果仍需检查并保存，调用计入账号用量。

提交规则支持同一浏览器限一次、允许修改、重复禁止或覆盖。浏览器凭证保存在本地，清理浏览器数据会丢失识别；严格限制身份时使用名单以及学号唯一规则。提交记录与填写草稿会在同一浏览器恢复。

名单支持 UTF-8 CSV 和 XLSX，首行用字段名或字段标识。学号等带前导零的数据应在 Excel 中存为文本。选择参与名单匹配的字段后，服务端要求它们来自名单中的同一行；姓名唯一匹配时自动填充学号，重名时需要补充完整信息。浏览器不会下载整份名单。

JavaScript 扩展使用函数体，参数为 values 和 files。values 按字段标识取值，files 包含 field/name/size/type。返回空字符串通过，返回错误文字阻止提交。脚本在浏览器隔离框架执行，不能访问应用登录状态或网络；仅作为浏览器交互规则。重要规则必须同时设为声明式字段规则，以便服务端校验。

收集列表按提交人、提交时间、字段和附件显示表格，可导出 XLSX 或附件 ZIP。命名模板使用字段标识，例如 `{student_id}-{name}`，导出保留扩展名并为同名文件追加序号。覆盖时保留原始提交时间并记录修改时间；重新上传文件会更新该记录的附件关联，原文件仍保留在待办中。
